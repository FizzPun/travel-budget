# ✈️ 旅算｜旅行預算與每日帳單工具

利用 AI 協助開發的互動 Web App，讓使用者規劃旅行預算、記錄不同幣別的支出，並整理行前及每日帳單。本作品以單一 `index.html` 完成，HTML、CSS、JavaScript 與世界地圖均整合於同一檔案。

**[🌐 開啟網站](https://fizzpun.github.io/travel-budget-/)** · **[📋 查看規格書](./spec.md)**

## 🎯 發想與目的

旅行花費通常分散在機票、住宿、交通、餐飲及購物，也可能使用不同幣別。本工具將支出統一換算成預算幣別，協助使用者了解整趟旅行的費用、是否超支，以及每人平均需準備的金額。

## 🛠️ 主要功能

| 功能 | 說明 |
| --- | --- |
| 🌍 世界地圖選目的地 | 可選日本、台灣、香港、澳門、美國及法國，設定新增支出的預設幣別 |
| 💰 旅行預算 | 設定旅行名稱、預算幣別、總預算、同行人數及另一顯示幣別 |
| 💱 自動匯率 | 開啟網頁或切換預算／顯示幣別時取得線上匯率，可手動更新與設定 |
| 🧾 多幣別帳單 | 每筆支出可選自己的幣別，支援新增、修改與刪除 |
| 🗓️ 每日行事曆 | 可選填 1～365 日，查看「行前」及第 1～N 日的帳單與小計 |
| 👥 平均分攤 | 顯示總支出、剩餘預算及每人平均費用，超支時提示 |
| 📊 花費分類 | 依交通、住宿、餐飲、門票、購物及其他顯示支出比例 |
| 💾 自動保存 | 在同一瀏覽器保留旅行設定、目的地與帳單 |

支援幣別：`JPY` 日圓、`TWD` 台幣、`MOP` 澳門幣、`HKD` 港幣、`USD` 美元、`EUR` 歐元。

## 🚀 使用方式

1. 開啟網站，點選地圖標記或目的地按鈕。
2. 輸入旅行名稱、總預算與同行人數，選擇預算幣別。
3. 若要按日記帳，勾選「加入旅行日數」，輸入日數。
4. 在行事曆點選「行前」或某一天，再填寫支出項目、類別、幣別與金額。
5. 按「新增支出」，查看清單及即時更新的預算結果。
6. 可切換「全部支出」或「未指定日期」，也能修改既有帳單。

也可以按「載入範例」體驗。此操作會先確認，再取代目前的設定與帳單。

## 📌 計算與資料說明

- 每筆費用先換算成預算幣別，再加總；每人費用為總額除以同行人數。
- 每日篩選只影響清單，上方預算概覽始終包含整趟旅行及行前費用。
- 目的地選擇只設定新支出的預設幣別，既有支出與預算保留。
- 更換預算幣別後，請重新確認總預算的數值；既有支出保留原始金額與幣別。
- 線上匯率為每日參考資料，實際換錢或刷卡金額可能不同。手動匯率優先使用，按「此組恢復自動」可移除手動設定。
- 更新失敗時沿用已保存匯率；缺少必要匯率時顯示「待換算」。
- 縮短行程時，超出行程的帳單經確認後改為「未指定日期」，保留金額；行前帳單保留。
- 資料儲存在瀏覽器的 `localStorage`，不跨裝置同步；清除瀏覽器資料可能移除紀錄。分攤採所有人平均分攤，不處理個別付款人及欠款結算。

## 💻 本機開啟與發布

下載 `index.html` 後，直接用瀏覽器開啟即可。自動匯率功能需要網路連線。

本儲存庫使用 GitHub Pages，發布來源為 `main` 分支的根目錄。更新網站時，上傳新版 `index.html` 並提交至 `main`，等待重新部署完成。

## 🤖 AI 協作過程

先與 AI 討論旅行預算工具的用途並整理規格，再利用 Vibe Coding 製作第一版；依操作需求逐步加入自動匯率、多幣別帳單、世界地圖、旅行日數、行前分類及 emoji，最後整理為單一 HTML，並透過 GitHub Pages 發布。
